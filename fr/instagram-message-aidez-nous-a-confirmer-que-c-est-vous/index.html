Ce que cela veut dire

Instagram veut vérifier qu’une vraie personne possède le compte, souvent après une activité inhabituelle. Il demande en général un selfie vidéo ou un code.

La première heure

  1. Utilisez votre appareil et réseau habituels.
  2. Entrez le code ou filmez le selfie lentement.
  3. En échec, attendez avant de réessayer.
  4. Ne faites confiance qu’aux e-mails de security@mail.instagram.com.
